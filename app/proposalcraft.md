MCP server for Claude Desktop that drafts client proposals in your voice. Save 2-3 past winning proposals as style examples; ProposalCraft provides them as context when Claude drafts new proposals from a brief. Includes analyze_brief, draft_proposal, and load_examples (12 bundled starter templates). Zero API key required, runs entirely locally.
